# test

Android app project using Kotlin, Jetpack Compose, and Gradle.

The first implementation milestone establishes the application scaffold and a shared
HTTP API client. The default emulator backend URL is `http://10.0.2.2:8080`.

## Build

Install JDK 17+ and Android SDK, then run:

```powershell
.\gradlew.bat :app:assembleDebug
```

Milestone commits are pushed individually to `https://github.com/namdzzgg-hash/test.git`
on the `main` branch.
